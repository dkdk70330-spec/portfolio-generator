생성기 사용 가이드

사용 전 꼭 확인!

  1. 수정 가능, 재배포 금지

    본 생성기는 여러 플랫폼의 캐릭터와 세계관을 한 곳에 통합시켜 유저에게 보여주기 위한, AI채팅 제작자용 아카이브를 목적으로 합니다. 배포 받은 분의 개인적인 코드 수정도 가능하지만, 생성기의 재배포는 금지합니다.

  2. 자동 임시저장 기능

    작성 내용은 자동으로 임시저장되지만, 캐시 삭제 등 브라우저의 설정이 변경되면 데이터가 삭제될 수 있으니 중간에 백업이 필요합니다. 캐시가 남아있을 경우 관리자가 레이아웃을 수정해도 번경되지 않으니, 가끔 ctrl+shift+R로 강제 새로고침 해주세요. 임시저장된 데이터에는 영향이 없습니다.

  3. 백업 기능

    텍스트 / 전체내용 zip / 배포용 zip 중 용도에 맞춰 백업해주세요. 배포용 zip은 사이트 생성용이며 생성기에서 불러오기가 불가능합니다. 배포 이후에도 전체내용 zip을 소장하는 것을 권장합니다.

  4. 사이트 배포

    netlify와 github 중 선택하여 배포한 뒤 사이트 링크를 이용합니다. github는 주소에 사용자의 id가 있으니 깡계 이용하세요.

  5. Github

    배포용 zip 다운로드 -> 압축 해제 -> 폴더 안에 든 모든 파일을 저장소에 업로드 -> 몇분 후 설정에서 site 생성

Netlify

배포용 zip 다운로드 -> 하단의 Netlify Drop을 클릭 -> 업로드 화면에 zip 파일 업로드 -> 업로드 완료 후 site 주소 확인
Netlify는 한달에 배포 20회 제한이 있으니 주의하세요.
